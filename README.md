# UniComedy v4

主な変更:
- NOROSHIの結果を大幅追加（2015〜2019、2022〜2026）
- NOROSHI 2024は公式サイト掲載の予選→敗者復活→準決勝→決勝進出を詳細化
- 確認できるNOROSHIチームは「漫才・ピン・コント」の3ユニットを表示
- 同一ユニット名が複数大会に出ている場合は青文字＋下線でタップ可能
- タップすると別大会の最高到達点を表示。同一大会内の予選/準決勝/決勝は最も先の段階だけ表示
- 同年の並びは、より後に開催される大学芸会個人戦 → 先に開催されるNOROSHI の順
- カード左上のサークルカラーに重なるラベル文字を白に変更

注意:
公開資料で確認できない3ユニット構成は推測せず未掲載です。
