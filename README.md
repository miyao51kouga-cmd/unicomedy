# UniComedy v2

大学芸会個人戦・NOROSHIの非公式結果アーカイブ。

## v2で追加
- 優勝カードを所属サークル色（不明時は大学イメージ色）に変更
- 大会一覧をクリックすると詳細ダイアログを表示
- 「決勝進出」「準決勝進出」「敗者復活戦進出」を大会ごとに表示できるデータ構造
- 2023大学芸会：公式サイトに残っている予選1〜10日目、敗者復活進出を収録
- 2025大学芸会：公式Xで確認できた準決勝進出者・決勝進出者から順次収録
- 検索対象を詳細進出者にも拡張
- 各大会詳細に出典リンク表示

## 色を変える方法
`app.js` の `CIRCLE_COLORS` を編集してください。
例:
`["早稲田大学お笑い工房LUDO", "#f28c28"]`

## GitHub/Vercelへの反映
このフォルダの `index.html` `style.css` `app.js` `README.md` を既存リポジトリに上書きして Commit すると、Vercelが自動再デプロイします。
