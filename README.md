# UniComedy v3

ユーザー指定の Wikipedia「大学芸会 (お笑い)」掲載情報を参照し、大学芸会の歴代記録を大幅拡充した版です。

## 追加内容
- 個人戦 2011〜2025（2020は中止表示）
- 各年の優勝・準優勝・3位・審査員賞（掲載されている範囲）
- 決勝進出者
- 2012〜2015の準決勝進出者
- 2012〜2023の敗者復活戦進出者（Wikipedia掲載範囲）
- 2024・2025の準決勝進出者
- 旧・大学芸会団体戦 2012〜2014の上位結果
- 既存のNOROSHI 2022〜2026データを維持

## 出典
Wikipedia「大学芸会 (お笑い)」をユーザー指定の補助ソースとして参照。
Wikipedia内で示されている大学芸会公式X、旧公式ブログ、PassMarket等の一次資料も可能な範囲で確認してください。
